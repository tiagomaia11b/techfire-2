Passo a passo

Antes, deixe o banco de dados pronto — é nele que o GPS é gravado.

Ligue a Pixhawk no Raspberry Pi

O jeito mais fácil é um cabo USB da Pixhawk numa porta USB do Pi (aparece como /dev/ttyACM0). Também dá para usar a porta TELEM2 nos pinos do Pi:

Pixhawk TELEM2Raspberry Pi
TXGPIO15 · RX (pino 10)
RXGPIO14 · TX (pino 8)
GNDGND (pino 6)
5Vnão ligar

Pela TELEM2: no Mission Planner ajuste SERIAL2_PROTOCOL = 2 e SERIAL2_BAUD = 57. No Pi, rode sudo raspi-config › Interface Options › Serial Port: shell Não, hardware Sim. A porta será /dev/serial0.

Instale as bibliotecas no Pi

python3 -m venv ~/gf
~/gf/bin/pip install pymavlink requests

Configure o script

Copie raspberry/enviar_gps.py para o Pi e edite as linhas do topo: o endereço da pasta api/ do site, a mesma CHAVE_API do api/conexao.php e a porta da Pixhawk.

SITE_API = "https://SEU-SITE.com/api/"
CHAVE    = "a-mesma-chave-do-conexao.php"
PORTA    = "/dev/ttyACM0"     # USB  ·  TELEM2: "/dev/serial0"
BAUD     = 115200             # USB  ·  TELEM2: 57600

Teste sem o drone

O modo simulado envia posições falsas. Se elas aparecerem no mapa acima, o caminho Pi → banco → site está funcionando.

~/gf/bin/python ~/enviar_gps.py --simular

Rode com o drone

Com a bateria ligada e o GPS a céu aberto (espere 1–2 minutos para pegar os satélites):

~/gf/bin/python ~/enviar_gps.py

Faça começar sozinho

Em crontab -e, adicione (troque pi pelo seu usuário):

@reboot sleep 30 && /home/pi/gf/bin/python /home/pi/enviar_gps.py >> /home/pi/gps.log 2>&1

Testar a gravação pelo site

Envia um ponto de teste para o banco, sem precisar do Raspberry Pi. Use a CHAVE_API do api/conexao.php.
