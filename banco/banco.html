Banco de dados

O banco MySQL guarda as posições do GPS, os voos e os focos encontrados. O Raspberry Pi grava pelos arquivos PHP da pasta api/, e o site lê de lá.

Raspberry Pi→api/*.php→MySQL→Site

    Criar banco e tabelas

    Executa o banco/guardflame.sql no MySQL. Pode clicar de novo sem medo: não apaga nada.

    Ou importe o arquivo pelo phpMyAdmin (aba Importar).

    Só mude se a pasta api/ estiver em outro servidor. Para todos, edite api.url no js/config.js.

    Passo a passo

    Tenha PHP e MySQL

    Para testar no seu computador: instale o XAMPP, ligue Apache e MySQL, copie a pasta do site para C:\xampp\htdocs\guardflame e abra http://localhost/guardflame.

    Para publicar: use uma hospedagem com PHP e MySQL. Crie o banco pelo painel dela e anote host, usuário, senha e nome do banco.

    Edite o api/conexao.php

    No XAMPP o usuário é root e a senha é vazia. Na hospedagem, use os dados do painel. Troque a CHAVE_API por uma senha só sua — ela também vai no Raspberry Pi.

    const DB_HOST    = 'localhost';
const DB_USUARIO = 'root';
const DB_SENHA   = '';
const DB_NOME    = 'guardflame';
const CHAVE_API  = 'troque-esta-chave';

    Teste a conexão

    Clique em Testar de novo no quadro Status. Tem que aparecer “PHP funcionando” e “Conectou ao MySQL”.

    Crie as tabelas

    Digite a chave no quadro Criar banco e tabelas e clique no botão. O status fica verde com as 4 tabelas.

    Ligue o drone

    Siga a página GPS para o Raspberry Pi começar a gravar a posição. Os dados aparecem no fim desta página.

    Tabelas

    usuarios

    Contas do site: nome, e-mail, senha criptografada e perfil.

    voos

    Cada missão: início, fim, área sobrevoada e observações.

    telemetria

    Posição GPS, altitude, velocidade, bateria e satélites, gravados a cada segundo pelo Raspberry Pi.

    ocorrencias

    Focos detectados pela IA: local, confiança, descrição e situação.
